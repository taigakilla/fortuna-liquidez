## Regras

- **IA no centro**: precisa participar da descoberta dos padrões **e** da decisão. Vale modelo treinado, LLM analisando o histórico, ou os dois. IA só para escrever código **não atende**.
- **Só dados do kit**: proibido dado externo. Qualquer ferramenta de IA pode ser usada (dados fictícios).
- **Valor**: nunca acima do solicitado nem de R$ 30 mil (se passar, é cortado no limite).
- **Code freeze 15h30** sem tolerância; arquivo depois disso não pontua.
- **Desclassificação**: entregar arquivo que a solução não gerou (ex.: CSV editado à mão).

## FAQ

| Pergunta | Resposta |
|---|---|
| Qualquer ferramenta de IA? | Sim, dados fictícios. |
| Consultar bureau para o histórico? | Não, já vem no backup. API é para os novos. |
| Limite de consultas ao bureau? | Não. Mas falha/demora, e tem que tratar. |
| E se o painel não ficar pronto? | CSV continua valendo nos 40%; critérios da banca ficam prejudicados. |
| Conversar com outros times? | Sim, mas sem compartilhar código, consultas ou arquivos. |
| Dúvida de negócio? | Com a pessoa que representa a Fortuna no evento. |
| A política atual está correta? | É a referência. Faz parte do desafio descobrir onde acerta e onde erra. |
