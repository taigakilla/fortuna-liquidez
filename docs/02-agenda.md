## Janelas de dúvidas com o cliente

- O cliente divulga os horários no canal do Teams.
- Cada time marca **até 15 minutos** dentro das janelas, pelo canal.

## Checkpoint 14h15

Até 14h15, mandar uma versão do CSV no canal. A organização devolve um relatório com:

- quantos pedidos têm decisão e os problemas encontrados;
- quantos aprovados e negados, valor total aprovado;
- em quantos pedidos a decisão difere da política atual.

O relatório **não** diz se a política está indo bem. O mentor recebe o mesmo relatório.

## Validação a qualquer hora

Mandar o arquivo no canal e pedir validação, quantas vezes quiser, até 15h30.

## Envio final

- Pasta do time no canal do hackathon no Teams.
- Nome `<time>_final.csv` (ex.: `liquidez_final.csv`).
- Vale o **último** enviado até 15h30.
- Código (zip ou link + README com o comando que gera o arquivo do zero) vai na mesma pasta.
